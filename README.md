# driftlang-web

Mono-repo for all driftlang.dev web properties.

## Apps

| App        | Domain                        |
|------------|-------------------------------|
| vitrine    | driftlang.dev                 |
| docs       | docs.driftlang.dev            |
| gotthard   | gotthard.driftlang.dev        |
| news       | news.driftlang.dev            |
| 25         | 25.driftlang.dev              |

## Packages

| Package    | Description                   |
|------------|-------------------------------|
| @drift/ui  | Shared tokens + components    |

## Dev

```bash
pnpm install
pnpm dev:docs      # start docs app
pnpm dev:vitrine   # start vitrine app
pnpm build:all     # build all apps
```
